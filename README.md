# halloffame12/ctx

Homebrew tap for [ctx](https://github.com/halloffame12/CTX) — codebase intelligence and context engine for AI coding agents.

## Install

```sh
brew tap halloffame12/ctx
brew install ctx
```

## Usage

```sh
ctx init     # index a project
ctx search   # find symbols
ctx context  # build context for an AI task
ctx mcp      # run the Model Context Protocol server
```

See the [full documentation](https://ctx.sumitchauhan.me/docs).
